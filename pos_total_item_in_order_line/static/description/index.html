POS Total Item in Order Line

What is the Module Function?

"POS Total Item in Order Line" refers to the total number of items or products in a single order line within a Point of Sale (POS) system. It is part of a sales transaction where a customer purchases one or more items from a business or store.

How to Use the Module

Step 1: Install App

Open the Apps menu, search for the "pos_total_item_in_order_line" module, and click Install or Activate.

Step 2: Results

Open Point of Sale → your looks example picture and your testing results.
